# 原作 · X 归档原创检查

**访问地址：<https://potervlag-cyber.github.io/x-originality-checker/>**

一个页面，一个入口：选择从 X 下载的归档 ZIP，自动读取归档中的全部帖子，显示分析原因和材料覆盖情况。本地检查无需解压、安装 Python 或登录 X；可选联网检查使用你指定的 10 条归档内帖子。

## 使用

1. 在 X 设置的“你的账号 → 下载你的数据归档”请求并下载 ZIP。
2. 打开网站，拖入 ZIP 或点击选择文件。单个文件最大 **300 MB（300 × 1024² 字节）**。联网开关默认关闭，上传后自动进行本地检查。
3. 如需联网查重，先打开联网开关再选择 ZIP。在随后弹出的窗口中填写 **10 个不同的 X 帖子链接**；每条都必须在这份归档中有完整、可检索的正文。弹窗同时提供服务地址、服务访问码和文字发送许可，连接项可在折叠的高级设置中调整。确认后自动完成本地检查、这 10 条帖子的联网查询和综合报告。
4. 同页查看综合结论、逐项原创要求的风险线索、参考概率及材料覆盖情况。更换文件即可重新检查；归档内不足 10 条合格正文时，可关闭联网开关进行本地分析。

页面和固定浏览器运行时首次加载约 14 MB。归档不上传到 GitHub 或其他服务；浏览器只选择性读取帖子数据与对应媒体，跳过私信、联系人等无关条目，不将整个 ZIP 解压到磁盘。刷新或关闭页面会清除本次结果。

默认范围是**归档中实际存在的全部帖子记录**，包括主帖、回复、引用帖和普通转帖，并分别统计。归档不一定包括删除的帖子、全部历史或完整长文；数据缺口会直接说明。没有原先的 2,000 条截断。大文件大小与需要分析的文本、媒体数量不同，实际速度和可处理容量取决于设备。

## 结果含义

检查账号内完全／近似文本重复、实际媒体文件哈希复用、反复互动请求，以及正文、来源和媒体缺口。数量和比例描述当前归档中的检查结果，不能证明版权归属或全网原创。

**原创通过概率是本工具按自设规则给出的主观参考估计。** 综合可比较的本人正文、去重后文本数量、重复及互动模板信号、材料构成与缺口，输出百分比、参考范围及每项调整原因。正文未重复占比另外显示，两项指标独立计算；没有可比较的本人正文时显示材料不足。

规则和权重由工具设计，尚未用真实审核结果校准；参考范围是主观不确定性范围，不是统计置信区间。这项估计只针对原创部分，不包含会员、展示量、认证粉丝等收益资格门槛。X 官方算法和十篇样本权重未公开，`official_probability` 仍为 `null`。离线概率不会因为联网查询自动变成经校准概率。图片／视频内容理解、跨语言与语义改写的完整核验尚未实现。

分析完成后显示原创贡献、自动化创建或发布、完全围绕变现、知识产权这四项已保存规则的风险线索强度、涉及条数和未知数，重复互动另外标为辅助检查。比例是风险线索涉及记录占非普通转帖记录的比例，不是官方不符合评分；证据不足显示“无法判断”。规则参考为 2026-10-06 已核查页面的项目保存释义，2026-10-07 官方页面重新读取返回 403，未声称本次实时复核通过，也未把四项当作官方完整清单。页脚链接已更正为 [X 原创内容奖励计划](https://help.x.com/en/using-x/original-content-rewards)。

本地检查始终覆盖全部归档记录。联网开关打开时，由你在上传后的弹窗中指定 10 条帖子，系统从当前归档读取正文，校验链接不重复、帖子存在且可检索；普通转帖、正文不完整或归一化后不足 24 字符的记录不接受。不会通过链接补抓归档缺失的 X 正文。所选 10 条不代表全部归档，也不能据此推断全网覆盖或账号整体原创程度。

可选的联网文字查重通过独立服务调用 Tavily 或 Brave 搜索 API，检索公开网页、读取候选正文并返回来源链接、相似片段及页面时间线索。来源证据纳入报告首部的综合结论和逐项风险说明；原归档信号参考概率保持其离线含义，不将未校准的联网相似度转换为官方通过概率。ZIP、媒体、私信及账号资料仍在本机；搜索提供商会收到所选文字片段。默认每条只查前 5,000 字，截断、失败、未选样本及搜索覆盖未知都明确记录。取消或失败会给出部分报告；已发送却未确认的批次记为执行未知，不自动重发，只有尚未发送的范围可继续。搜索不到不证明原创，相似不证明抄袭；本人同一 X 帖子会排除。

已保存的真实验收中，公开 MDN 引文在服务和浏览器流程中检出正文重合；另一段公开 Python 引文仍未检出，保留为已知漏检。成功样例证明链路可用，不能证明所有转载或改写都会被发现。

GitHub Pages 提供界面和本地分析，联网服务需要单独启动或部署；搜索 API 密钥仅放服务端环境变量。服务实现、配置、调用范围与启动步骤见 [联网查重说明](docs/WEB_CHECK.md)。没有配置搜索服务时会明确提示未执行，不以演示结果冒充实际联网查重。

推荐使用 **Render 免费 Web Service + Tavily**。下面的按钮按仓库 Blueprint 创建一个免费后端，提示在 Render 填写 Tavily key，并自动生成独立的服务访问码；步骤与免费版冷启动限制见 [Render 配置指南](docs/RENDER_SETUP.md)。只部署成功仍需完成真实查询验收。

## 开发和部署

Python 3.12+ 与 Node 22+：

```sh
python -m unittest discover -s tests -v
python -m unittest discover -s browser -p 'test_*.py' -v
node --test browser/test_runtime.js browser/test_archive.js browser/test_webcheck_client.js
python build_site.py --output _site --download-runtime
python -m http.server 8000 --directory _site
```

浏览器 Worker 用固定 Pyodide 0.27.7 运行 Python 规则。ZIP 按目录与文件片段读取，媒体哈希分块计算，避免整个 300 MB 文件转为 Base64。对无法解压、损坏、加密或超出支持资源边界的归档显示明确错误，不静默截取后给出全量结果。

浏览器支持单卷 ZIP 和 ZIP64（stored/deflate），包括 ZIP64 目录结束记录、中央目录扩展字段，以及仅本地文件头使用 ZIP64 的归档。处理边界：上传最多 300 MiB、目录最多 16 MiB / 200,000 个文件，单个帖子文件解压后最多 64 MiB、帖子文件合计最多 128 MiB、引用媒体合计最多 512 MiB、最多 500,000 条帖子记录。分卷 ZIP、损坏结构及超限数据会明确拒绝。独立长文文件尚未支持的结构会提示，不能把已扫描帖子记录数当作正文与媒体全部完整。

`main` 推送由 GitHub Actions 检查、构建并发布 Pages。构建只复制明确允许的程序文件，运行时按固定 URL、长度和 SHA-256 校验。见 [部署说明](docs/GITHUB_PAGES.md) 和 [第三方许可](deployment/THIRD_PARTY_NOTICES.md)。
