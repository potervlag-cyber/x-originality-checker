# 原作 · X 原创评估

中文 GUI，用于检查已提供帖子材料中的原创风险、补齐证据，并整理最多 10 篇申请候选。

**访问地址：<https://potervlag-cyber.github.io/x-originality-checker/>**

打开页面即可使用，无需安装 Python 或登录 X。首次运行会从本站下载约 14 MB 的浏览器 Python 运行时；初始化完成后可以点击“体验示例”。加载速度取决于网络和设备。

## 使用

1. 在“导入与资料”选择 JSON、CSV、填写后的 Markdown 提交表、X 帖子 JS，或筛选后的 ZIP；小批量材料可手动添加。
2. 填写账号与评估范围，补充来源原文、本人贡献、线程完整性及媒体关联。
3. 点击“运行评估”，复核逐帖理由，再到“申请候选”选择最多 10 篇。
4. 下载 JSON 项目以便继续编辑；导出 HTML 或 Markdown 报告用于阅读与分享。

只提供链接时，需要补充帖子正文。程序不会自动读取账号或来源网页。单文件最多 30 MB，项目最多 2,000 条；批量近似文本对比可能需要较长时间。操作说明与可填写模板可在界面内查看、下载，也位于 [materials](materials/)。

## 材料处理与结果边界

在线版通过 Pyodide 在浏览器内运行同一套 Python 检查规则。导入的帖子、来源原文与媒体文件不发送到本站服务端，也不上传到 GitHub；页面与运行时文件需要正常联网加载。媒体文件在浏览器内计算 SHA-256，项目仅保存文件名、类型和哈希。点击官方规则或来源链接会访问相应外部网站。

材料保留在当前页面内存中，需要手动下载 JSON 保存；刷新、关闭标签或清空项目可能丢失未保存内容。项目和报告包含原文，分享前检查内容。请只导入相关公开帖子，完整账户归档、私信、登录凭据、身份及支付材料不属于本工具所需材料。

已实现：账号内完全／近似重复、已提供来源文字重合、文件哈希重复、反复诱导互动提示，以及正文、媒体和线程缺口。未发现明显信号不代表官方认定为原创。

语义洗稿、跨语言改写、图片／视频内容理解、全网查重，以及与官方审核的一致性尚未验证。结果不是官方申请通过概率或版权结论；10 篇申请样本的官方审核权重未见公开说明。

## 开发

使用 Python 3.12 或更新版本，无第三方 Python 依赖：

```sh
python -m unittest discover -s tests -v
python build_site.py --output _site --download-runtime
python -m http.server 8000 --directory _site
```

构建器只发布明确列出的界面、检查规则、演示数据和说明文件。Pyodide 固定为 0.27.7，每个运行时文件按固定 URL、长度和 SHA-256 校验。源码推送到 `main` 后由 GitHub Actions 发布 Pages，详见 [部署说明](docs/GITHUB_PAGES.md)。

Python 本机服务仍可通过 `python app.py` 启动。在线版与本机版使用同一套导入、检查与报告函数，不把相同规则等同于官方审核的一致性。

第三方浏览器运行时许可见 [THIRD_PARTY_NOTICES](deployment/THIRD_PARTY_NOTICES.md)。
