# X 原创检测：如何准备和提交材料

这份说明帮助你整理账号和帖子，供原创风险评估使用。现已提供“原作 · X 原创评估”浏览器 GUI 第一版。评估用于发现材料中的重复、来源文字重合和原创贡献缺口，并整理申请样本；最终收益申请结果由 X 决定。

## 使用第一版 GUI

1. 打开在线网站即可进入 GUI；首次访问需要下载浏览器运行组件，无需安装 Python。
2. 进入“导入与资料”，导入 JSON、CSV、填写后的 Markdown 提交表、X 帖子 JS 或筛选后的 ZIP；也可以手动添加帖子。
3. 确认账号、日期范围和完整性；在“帖子与证据”中补充来源原文、本人贡献和媒体文件。
4. 点击“运行评估”，逐条查看理由，再到“申请候选”选择最多 10 篇。
5. 保存 JSON 项目以便下次继续；需要分享时另行导出 HTML 或 Markdown 报告。

第一版只在本机处理材料，不自动抓取 X 账号或来源网页。只有链接时可以先登记，但需要补正文才能对比。单个帖子材料文件最多 30 MB，项目最多 2,000 条帖子；ZIP 支持 `tweets.js`、`posts.json`、`posts.csv`、`提交表.md` 等允许的帖子文件，并只读取明确关联的媒体。更多操作见应用目录的 README。

## 1. 先选择评估范围

| 你想检查什么 | 最少需要提供 | 评估覆盖范围 |
|---|---|---|
| 已选好的申请样本 | 账号链接、拟提交的 10 篇链接、对应完整内容和媒体 | 提交的样本 |
| 一段时间内的账号内容，并挑选申请样本 | 账号链接、起止日期、该期间全部本人发帖及媒体 | 提交时间段内实际取得的内容 |

尚未选好 10 篇时，可以先提交历史内容，后续从中挑选候选。只有部分帖子时也能开始，但需要注明选择方式和缺失范围。

## 2. 填写账号和时间范围

复制并填写配套的《X原创检测提交表模板》。填写：

- 账号链接或 `@用户名`。
- 评估目的：申请样本初评／指定时间段账号评估／账号评估并推荐申请样本。
- 账号评估需填写起止日期及日期使用的时区，例如 `Asia/Shanghai（UTC+8）`；仅做样本初评时，这两项可填“不适用”，每篇帖子的时间另行记录。
- 材料整理日期；是否包含该期间全部本人发帖：是／否／不确定。
- 已知缺失，例如部分视频、线程后续内容、无法访问或已删除的帖子。

账号评估可以先从近 90 天开始。**这是资料整理建议，X 没有公开原创审核的历史范围。** 请写出实际起止日期；例如按北京时间选取 `2026-07-09 至 2026-10-06`，表示包含这两个日期当天的内容。

## 3. 准备帖子：任选一种整理方式

### 方式 A：手动整理，适合样本较少

1. 打开需要评估的帖子，使用分享菜单的“复制链接”（名称以实际界面为准）。每条链接单独一行。
2. 将帖子完整文字复制到提交表的“单篇帖子记录”。引用帖正文只填写本人新增的文字，被引用原文放入对应来源记录。保留原文，补充说明另外填写。
3. 填写发布时间及主帖／回复／引用帖／普通转帖类型。时间无法确定时写“未知”。
4. 帖子有图片或视频时，提供对应文件，并注明该文件属于哪篇帖子。
5. 多条帖子组成的线程要逐条提供，并标出顺序；X Article 等长文需提供完整正文。

可以先登记链接；第一版不会访问链接，检测前仍需补充正文和媒体。另存的 `.txt` 或其他正文附件不会被自动读取，请将正文粘贴到模板或 GUI。纯截图适合作为辅助材料；截图无法覆盖的视频、长文或完整线程仍需另补。

账号评估时，请保留范围内的主帖、回复、引用帖和普通转帖记录，分别标注类型。普通转帖记录用于解释发布构成，不当作本人原创候选。

### 方式 B：从本人 X 数据归档中整理，适合帖子较多

**先在自己的电脑下载并解压，再整理本次需要的内容。完整归档可能包含私信、通讯录等账户资料，请只发送筛选后的材料。**

电脑端按 X 官方说明操作：

1. 登录自己的 X 账号，打开左侧“更多”，进入账户设置中的“你的账号 / Your account”；具体菜单名称以当前界面为准。
2. 选择“下载你的数据归档 / Download an archive of your data”。
3. 在 X 官方页面自行完成密码确认及邮箱或手机验证码验证。
4. 选择“请求数据 / Request data”。
5. 等待 X 的邮件或应用通知；归档准备可能需要数天。
6. 回到 X 官方设置页面下载 ZIP 文件，在本机解压。

官方步骤：[如何下载你的 X 归档](https://help.x.com/en/managing-your-account/how-to-download-your-x-archive)；本说明核查日期为 2026-10-06。

从解压内容中，只整理以下资料到一个新文件夹：

- 本次时间范围内的本人公开帖子：正文、时间、帖子标识或链接、类型、媒体引用。
- 与这些帖子对应的图片、视频、GIF；不要整批复制包含其他内容的媒体目录。
- 原文件能保留的线程、回复和引用关系。

不同归档版本的文件名和目录可能不同，因此这里不指定固定文件名。不要只凭文件名判断是否包含私信。无法确认时，可先提供脱敏后的文件名或目录列表，确定哪些文件适合整理；此时先不发送归档正文。

第一版支持常见 X 帖子 JS 和筛选 ZIP，但尚未确认所有归档版本均能完整解析。导入后应核对正文、时间、帖子类型和媒体关联。也可以把需要的公开帖子整理到配套提交表，或提供经检查仅含相关公开帖子的 JSON / CSV 文件。

归档缺少长文全文、媒体或线程分段时，另行补充。无法补充的内容写入“已知缺失”。

## 4. 列出拟提交的 10 篇

如果你的申请页面要求选择 10 篇，把拟提交链接逐行放入提交表的“申请候选”。

- 已选好：列出 10 篇，并确认每篇都能关联到完整正文和对应媒体。
- 尚未选好：填写“请从历史帖中推荐”。
- 不足 10 篇：提交实际数量，并注明数量；先评估现有样本。

不要为补足数量重复填写同一篇。线程如何算一篇、哪些类型可以选择，请按你实际申请页面的说明操作；拿不准时保留线程全体链接并备注。

这 10 篇的官方审核权重未见公开说明，样本评估与账号整体评估应分别呈现。

## 5. 给涉及他人素材或跨平台发布的帖子补充来源

纯本人写作且没有引用素材的帖子，可以先不补来源。以下情况建议逐篇填写“来源与原创贡献”：

- 使用他人的文字、图片、视频、截图或研究材料。
- 翻译、改编、总结、评论他人内容。
- 同一作品在其他平台也出现过，需要说明是否为本人跨平台发布。

每篇填写：

```text
对应帖子链接或编号：
素材归属：本人制作／他人来源／混合素材／不确定
来源或本人跨平台发布链接：
来源原文（用于文字对比，可选）：
本人新增的分析、观点、报道或创作：
创作方式：本人创作／工具辅助／自动生成或自动发布／其他／不确定
素材使用权说明（有则填）：
证据文件名（有则填）：
```

不知道来源就写“未知”；无需猜测或补造记录。创作方式用于提供背景，不按一个选项直接认定合格或违规。

草稿、原始拍摄文件、设计源文件、本人首发记录等可以作为辅助证据。先提供与争议内容相关的部分即可；只有“这是我做的”自述时，会记录为作者声明。素材授权说明用于检查使用权，不能单独证明符合原创要求。

第一版不会访问来源链接。需要检测文字重合时，在 GUI 或模板中粘贴相关来源原文；只有链接的来源会标记为未完成对比。图片和视频仅计算实际文件哈希，画面内容和创作归属仍需人工复核。

## 6. 如需另行人工核对收益资格，再补资格信息

第一版不会导入、保存或自动检查本节资格信息，只检查原创内容时可跳过本项。需要另行人工核对收益申请资格时，请单独保留 Creator Studio 当前显示的文字或脱敏截图，包括：

- 计划名称、资格状态及记录日期。
- 会员档位、认证关注者数量、页面显示的有效展示指标及其统计时间范围。
- 账号限制、申请结果或拒绝原因（如有）。

可以复制文字，或提供遮住邮箱、手机号、身份信息及支付信息的截图。展示指标请保留完整名称，避免把总展示次数误写为符合计划要求的展示次数。

## 7. 整理成一个提交文件夹

建议结构如下，未使用的目录可以省略：

```text
X原创检测_用户名_整理日期/
  提交表.md
  帖子材料/          # 多篇正文、长文或筛选后的数据文件
  媒体/              # 本次帖子对应的图片、视频、GIF
  来源与创作证据/    # 可选
  资格信息/          # 可选，脱敏截图或文字
```

帖子较少时，所有文字都可以写在一个提交表中。媒体建议以帖子编号命名，例如 `P001_图1.jpg`、`P001_视频1.mp4`，并在帖子记录里写出相同文件名。

本机自查时，将支持的帖子材料导入 GUI，媒体可以在单篇编辑窗口中关联。交给他人评估时，将筛选后的文件夹打包为 ZIP，通过双方约定的文件接收渠道发送；只有文字时也可以发送填写后的提交表。

## 8. 发送前确认

- [ ] 账号、评估目的已填写；账号评估的实际时间范围和时区已填写，仅样本初评可填“不适用”。
- [ ] 每篇帖子有链接或标识，正文保持原文，媒体与帖子对应。
- [ ] 线程或长文提供了完整内容，缺失部分已注明。
- [ ] 账号评估材料的完整性和选择方式已说明；没有用精选 10 篇代替全部历史记录。
- [ ] 引用素材和跨平台发布的归属尽量说明，未知信息明确标注。
- [ ] 只发送本次相关材料；没有完整账号归档、私信、通讯录、密码、验证码、Cookie、Token、身份证件或支付资料。

首次提交不必备齐所有创作证据。先提供账号、范围和帖子材料，收到需要核实的具体事项后再补充。

报告应标明：实际覆盖日期和帖数、样本选择方式、已知缺失，以及文字、图片、视频分别完成了哪些检查。未获取到的内容会列为待补充；不知道总帖数时，不给出精确覆盖率。

配套材料：[X原创检测提交表模板](template.md)。
