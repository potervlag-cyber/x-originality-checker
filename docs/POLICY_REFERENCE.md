# 原创内容规则的来源与检查边界

原创内容要求应链接至 [X Original Content Rewards](https://help.x.com/en/using-x/original-content-rewards)。原页脚保留了 [Creator Revenue Sharing](https://help.x.com/en/using-x/creator-revenue-sharing) 的硬编码链接，未随项目已记录的计划转换更新，因此指向旧收益说明。

本版参考项目在 **2026-10-06** 已核查的官方页面记录及保存释义。**2026-10-07** 对上述两个英文官方页面及对应中文路径重新执行公开 HTTP 读取，结果为 403；浏览器运行时也未成功启动。因此本版没有把现行官方正文记为重新核验成功，下面不是逐字原文或官方完整要求清单。参考状态随报告保存在 `policy_checks.source` 中。

| 保存要求的释义 | 工具能提供的证据 | 必须保留的未知 |
| --- | --- | --- |
| 增加作者视角的解读、分析或背景可以形成原创贡献；照搬、微改或没有实质新视角的拼接不算该计划下原创 | 已提供来源或公开检索来源的文字重合、作者所列新增贡献 | 作者身份、新增贡献的实质、未收录来源、跨语言及语义改写；相同文本也可能为本人跨平台发布 |
| 自动化创建或发布属于不符合奖励条件的情形 | 明确的创作方式声明 | 声明的真实性与实际流程；归档正文不能证明创作方式，保存页面未逐一解释所有 AI 辅助场景 |
| 完全围绕变现教学、变现讨论或最大化收益的内容不符合奖励条件 | 完整文字中涉及变现教学或收益提升的弱表述线索 | 整篇是否完全围绕该主题；提到收益本身不构成不符合要求 |
| 原创内容仍需满足知识产权要求 | 与来源重合后需要核对权利的提示 | 作者、许可、授权与权利状态；链接、注明出处、声明和文件哈希均不能证明权利合规 |

重复互动请求单独作为辅助线索展示，不新增为官方原创条款。账号内相同正文仅作为材料多样性的参考，不计为外部来源风险。普通转帖不计入当前内容报告的分母；这不表示转帖会导致账号违规。回复和引用会纳入工具的非普通转帖记录，也不表示其曝光或内容已满足奖励资格。

辅助风险面板显示 **工具风险线索强度**，并非官方认定。`signal_percent = signal_count / denominator × 100`，分母为本次非普通转帖记录；同一项每条记录只计一次。`assessed_count` 是已进行该项线索筛查的记录数，`unknown_count` 是没有达到筛查条件的记录数。无证据显示“证据不足”，已有检查但无信号显示“未发现风险线索”；两者均不换算为符合满分。

## 原创要求加权符合率

四项默认工具权重为原创贡献 50、创作方式 20、完全围绕变现 10、知识产权 20。用户可调整总和为100且原创贡献大于0的权重；这些不是X官方权重。语义模型必须给出实际帖子原文及实际获取的来源片段，才能对相对于这些来源的新增贡献作参考评分；查不到来源、不完整正文、伪造摘录、失效响应保留未知。创作方式和素材权利缺少证明时不由模型猜测。

以本次所选的全部 `N` 条主帖为范围，要求 `i` 的权重为 `w_i`，有效内容参考评分 `s_ij` 为0至100：

- 加权覆盖 `K = Σ w_i × 有效评分帖数_i / N`。
- 已有加权贡献 `A = Σ w_i × Σ有效(s_ij / 100) / N`。
- 已评估部分加权符合率为 `A / K × 100`，仅在 `K > 0` 且原创贡献有有效评分时提供。
- 综合卡参考范围为 `[A, A + 100 − K]`，未核验权重为 `100 − K`。

范围是未知项取0至100时的算术上下限，不是统计置信区间或审核概率。缺失/失败/未处理仍在N中，不通过缩小分母虚增结果；全未知为null，不是0%，也不视为符合。仅主题有分、原创贡献全未知时不显示综合数字。帖子数量只确定本次范围与平均口径，不增加符合分，内部重复观察及弱风险线索不直接参与此率。

例如十条均获得原创贡献80、主题100，其余两项未知，则A=50、K=60，综合范围50%至90%，已评估部分83.3%，未知权重40%。这些结果只描述已选十条的参考内容评估。

联网检索中的同一 X 帖子不作为外部重合证据；有可靠时间证据表明晚于被检帖的来源不计为负面原创线索。作者未知的重合仍需复核。只获得搜索摘要的线索最多为“低（仅弱线索）”；成功读取网页正文后的高度重合可以显示“中（需复核）”。本工具没有提供官方不符合百分比或官方评分。

会员、认证粉丝、首页时间线曝光、所在地区、账号状态和其他收益资格属于账号层面，不能从这份内容报告核验，保存在独立 `account_eligibility` 项中。
