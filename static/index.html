如何从 X 获取归档？

在 X 打开「设置和隐私 → 你的账号 → 下载你的数据归档」，按 X 提示申请并下载 ZIP，然后在这里选择原始压缩包。

归档只反映导出时保留的内容，已经删除或未导出的帖子无法检测。较大的媒体文件会增加浏览器内存占用，建议使用电脑浏览器。
